<objective>
Move `CONTEXT_PARAMETERS.md` and `REPRESENTATION_MODIFIERS.md` from
`how/concepts/research/important/` to `how/concepts/research/essential/`, then repair
every cross-reference (inbound and the two files' own outbound sibling links) that the
directory change affects, so the documentation tree has zero dangling links afterward.

Per the tier criteria in `how/concepts/research/README.md` — essential is "Semantic
bedrock — the language's skeleton. Without these, Orthon cannot exist" vs. important is
"Makes the language usable and expressive — the language's muscles" — both concepts
describe semantic bedrock rather than ergonomic sugar: `CONTEXT_PARAMETERS.md` proposes a
fundamental parameter-space split (data vs. context) that the file itself frames as "an
independent semantic axis, co-equal with data and effects," and
`REPRESENTATION_MODIFIERS.md` proposes how any user-defined type is materialized in
memory, extending the Data + Data Modifiers dichotomy into the type domain. Both sit
closer to Primitive Blocks (Phase 3) territory than an ordinary "important" feature.

Purpose: Correct a tier-classification mistake before Phase 4 planning reads the
`essential/`/`important/` split as ground truth for scoping decision-pipeline work.

Output: Both files relocated via `git mv` with untouched bodies; the one real inbound
cross-reference and the two real outbound sibling-links that break because of the move
are updated; no other file is touched.
</objective>
