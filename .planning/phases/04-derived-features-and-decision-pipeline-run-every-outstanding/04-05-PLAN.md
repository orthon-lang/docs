The semantics are fully expressible via primitives (literal + pack). However, if the compiler must recognize these for optimization (e.g., inline array allocation), it bends toward Language.
    - Decision: Classify as StdLib with compiler recognition for optimization (same pattern as Phase 3 D-05's approach to syntactic sugar).

    **DATACLASSES:**
    - Classification per D-03: Likely StdLib or compiler macro — auto-generated `==`, `@hash`, `@string` for data-carrying types. Expressible via DERIVE_SERIALIZATION (Plan 04-07, important tier) or a macro.
